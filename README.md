# 💻 Project-KakaoChatbot-GPTSkinManager

> ChatGPT 기반 피부 고민 상담 및 올리브영·뷰티컬리 스킨케어 제품 추천 카카오톡 챗봇

## 🧴 프로젝트 소개

### 주제

ChatGPT와 웹 크롤링을 활용하여 사용자의 피부 고민에 대한 상담을 제공하고, 피부 타입에 맞는 스킨케어 제품을 추천하는 카카오톡 챗봇입니다.

### 주제 선정 배경

평소 피부 관리에 관심이 많아 다양한 피부 고민에 대한 정보를 찾고, 피부 타입에 맞는 화장품을 탐색하는 과정에서 여러 불편함을 경험했습니다. 이러한 경험을 바탕으로 피부 관련 정보를 보다 쉽고 효율적으로 탐색할 수 있는 챗봇을 개발하고자 했습니다.

**1. 피부 고민에 대한 정보 탐색의 번거로움**

피부 트러블이나 건조함 등 다양한 피부 고민이 생길 때마다 네이버, 유튜브 등 여러 플랫폼에서 관련 정보를 개별적으로 검색해야 했습니다. 하지만 검색 결과에는 관련성이 낮은 콘텐츠나 광고성 정보가 많아, 실제로 필요한 정보를 선별하는 데 상당한 시간이 소요되었습니다.

**<해결 방안>**
- ChatGPT를 활용하여 사용자의 피부 고민에 맞는 맞춤형 상담 및 정보 제공
- 네이버 검색 결과와 관련 유튜브 영상 링크를 연계하여 추가 정보 탐색 지원
- 사용자 주변의 피부과를 검색할 수 있는 기능 제공

**2. 피부 타입에 맞는 화장품 선택의 어려움**

피부 타입과 고민에 적합한 스킨케어 제품을 찾는 것 역시 쉽지 않았습니다. 특히 건성 및 아토피 피부에 적합한 제품을 탐색하면서, 검색 플랫폼의 광고성 콘텐츠와 제한적인 제품 정보로 인해 객관적으로 다양한 제품을 비교하기 어렵다는 점을 느꼈습니다.

**<해결 방안>**
- 피부 타입별 특징과 정보를 제공하여 사용자가 자신의 피부 유형을 파악할 수 있도록 지원
- 올리브영과 뷰티컬리의 인기 스킨케어 제품 정보를 수집하여 피부 타입에 맞는 제품 추천

## 🧩 주요 기능

### 1. 피부 고민 상담

[주요 기능 - 피부 상담 Wiki로 이동](https://github.com/rsohyun/kakaochatbot_GPTSkinManager/wiki/주요-기능-소개-:-내-주변-피부과-찾기)

- 사용자의 발화를 기반으로 프롬프트 엔지니어링을 적용한 입력값을 구성하여 ChatGPT에 전달
- ChatGPT의 응답을 활용해 피부 고민에 대한 상담 및 관련 정보 제공

### 2. 스킨케어 제품 추천 (올리브영·뷰티컬리)

[주요 기능 - 제품 추천 Wiki로 이동](https://github.com/rsohyun/kakaochatbot_GPTSkinManager/wiki/주요-기능-소개-:-제품-추천)

- 사용자가 자신의 피부 타입을 선택하고, 제품을 탐색할 플랫폼(올리브영 또는 뷰티컬리)을 선택
- Selenium을 활용해 각 플랫폼의 인기 제품 검색 결과를 실시간으로 수집
- 수집한 제품 정보를 바탕으로 추천 상품 제공

### 3. 내 주변 피부과 찾기

[주요 기능 - 주변 피부과 찾기 Wiki로 이동](https://github.com/rsohyun/kakaochatbot_GPTSkinManager/wiki/주요-기능-소개-:-내-주변-피부과-찾기)

- '주변 피부과' 검색 결과가 연결된 네이버 지도 링크 제공
- 사용자가 지도에서 주변 피부과의 위치와 정보를 확인할 수 있도록 지원

### 4. 내 피부 타입 알아보기

[주요 기능 - 피부 타입 알아보기 Wiki로 이동](https://github.com/rsohyun/kakaochatbot_GPTSkinManager/wiki/주요-기능-소개-:-피부-타입-알아보기)

- 피부 타입별 특징과 정보를 텍스트로 제공
- 사용자가 각 유형의 특징을 비교하여 자신의 피부 타입을 간단하게 파악할 수 있도록 지원
